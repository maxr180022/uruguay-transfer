# RusWeo — Telegram Mini App / Web

Текущая промежуточная сборка: **RusWeo 1.0.1**

Этот репозиторий содержит веб-часть RusWeo, которая используется Telegram Mini App и как источник общих страниц проекта.

## Файлы

- `index.html` — главный экран Telegram Mini App.
- `booking.html` — форма бронирования трансфера.
- `guide.html` — «Гид по Уругваю».
- `rusweo_logo.png` — основной логотип RusWeo.
- `rusweo_app_icon.png` — квадратный вариант полного логотипа RusWeo.

## Что изменено в 1.0.1

- Ребрендинг пользовательского интерфейса UruWay → RusWeo.
- Сохранена рабочая splash-анимация запуска.
- Логотип для splash встроен непосредственно в `index.html`, чтобы его загрузка не зависела от preview.
- Верхняя панель гида уменьшена и опущена ниже.
- Добавлена поддержка `safe-area-inset-top`, чтобы заголовок и кнопка «Поддержать» не попадали под вырез камеры в Android/WebView.
- Рабочая логика бронирования, партнёрских переходов, новостей и авторизации не изменялась.

## Важно

Некоторые старые технические идентификаторы намеренно остаются с именем UruWay/uruway:
- `window.UruWayAndroid`
- `window.UruWayApp`
- localStorage-ключи `uruway_*`
- действующие URL Cloudflare/Apps Script

Это внутренние совместимые идентификаторы. Их переименование без отдельной миграции может сломать работающую систему.
