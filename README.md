# RusWeo — Telegram Mini App / Web

Текущая промежуточная сборка: **RusWeo 1.0.5**

## Новое в 1.0.4

Splash-заставка переведена на фирменное видео пользователя.

Чтобы заставка не выглядела как отдельный видеоблок:
- `<video>` не имеет рамки, карточки, тени или controls;
- фон видео визуально соединён с белым фоном splash-экрана;
- края растворяются в общий экран мягкими градиентами;
- видео располагается как часть композиции экрана, а не как отдельная вставка;
- поверх того же экрана плавно появляется приветствие RusWeo;
- после окончания видео весь splash целиком плавно исчезает;
- если видео не загрузится, предусмотрен резервный статичный логотип и автоматический вход в приложение.

Видео оптимизировано:
- H.264 MP4;
- 960×720;
- 30 fps;
- без звука;
- около 5.2 секунды;
- fast-start;
- размер меньше 1 МБ.

## Исправление 1.0.4

Убрана заметная прямоугольная граница видеозаставки:
- фон splash подогнан под светло-серо-голубой тон краёв видео;
- верхний и нижний край видео растворяются через CSS mask;
- переход к белой зоне приветствия сделан плавным;
- видео больше не должно восприниматься как отдельная вставленная карточка.

Бизнес-логика не менялась.
