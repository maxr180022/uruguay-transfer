# RusWeo — Telegram Mini App / Web

Текущая промежуточная сборка: **RusWeo 1.0.2**

## Новое в 1.0.2
Фирменная splash-анимация:
- светлый фон без чёрной подложки;
- розовый и синий элементы знака сходятся с разных направлений;
- `Rus` и `Weo` приходят навстречу друг другу;
- элементы собираются в цельный RusWeo;
- появляется мягкий световой импульс;
- затем проявляются приветствие, подпись и точки загрузки;
- splash плавно исчезает.

Анимационные PNG-слои встроены непосредственно в `index.html`, поэтому splash не зависит от сетевой загрузки отдельных картинок.
