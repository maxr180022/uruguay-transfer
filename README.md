# RusWeo

**Текущая версия:** 3.1.16 / V89  
**Android:** code93  
**Web revision:** 31089

RusWeo — единая система для трансферов и работы водителя в Уругвае.

Один общий web-интерфейс используется одновременно в:

- Telegram Mini App
- Android-приложении RusWeo
- GitHub Pages

Backend работает через Google Apps Script.

## Текущие возможности

### Клиент

- оформление трансфера;
- расчёт и отображение стоимости;
- Telegram-авторизация;
- уведомления по заказу;
- повторное бронирование;
- раздел партнёров;
- переходы к партнёрам с резервными способами открытия Telegram;
- кнопка **«Мы в Telegram»** → `https://t.me/rusweo`.

### Водитель

- активные и принятые заказы;
- история поездок;
- рабочие отчёты;
- чаевые и дополнительные доходы;
- корпоративные заказы;
- встроенный календарь работы;
- будущие подтверждённые заказы в календаре;
- плановая занятость по дням;
- открытие заказов непосредственно из календаря;
- постоянное Android-уведомление о ближайшем заказе;
- отдельное напоминание за 60 минут до поездки.

## Календарь V89

В водительском календаре доступны:

- навигация по месяцам и годам;
- фактически отработанные часы;
- будущие подтверждённые заказы;
- примерная продолжительность будущей занятости;
- несколько заказов в один день;
- окно со списком заказов выбранной даты;
- переход из календаря к конкретному заказу.

Google Calendar пока продолжает работать параллельно.

### Google Apps Script

Backend:

- `Code.gs`

Текущая backend-логика включает исправленную Telegram-авторизацию водителя.

### Android

Android является оболочкой над общим RusWeo Web App и содержит native-функции:

- WebView;
- Android bridge;
- foreground service;
- системные уведомления;
- напоминания о ближайшем заказе.

Текущий Android versionCode: **93**.

## Важно

Web-, backend- и Android-изменения являются отдельными слоями проекта.

Изменение web-интерфейса не требует пересборки Android, если native-код не менялся.

Изменение `Code.gs` не требует пересборки Android.

APK/AAB собираются только при изменении native Android-части или versionCode.
