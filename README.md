## Маршрутизация заявок

- STANDARD-заявки видит только STANDARD-водитель.
- BUSINESS-заявки видит только BUSINESS-водитель.
- Уведомления об отмене, статусах поездки и изменениях маршрутизируются по классу конкретной заявки.
- Активные заявки берутся из таблицы заказов; Google Calendar является дополнительным контуром занятости.

## Статусы поездки

Для принятой заявки в Telegram-карточке водителя доступны:

1. `🚗 Водитель выехал`
2. `▶️ Водитель начал поездку`
3. `✅ Водитель завершил поездку`

Переходы последовательные:
`confirmed → driver_enroute → trip_started → completed`

Клиент получает Telegram-уведомление на каждом этапе.

После завершения поездки клиенту автоматически показывается повторное меню бронирования.

- Колония-дель-Сакраменто;

Город без адреса не считается достаточным адресом подачи/назначения.

## Ограничение по времени бронирования

Новая заявка не может быть создана менее чем за 2 часа до поездки.

## Защита от дублей и задержек

- Используется `request_token`.
- Повторный запрос с тем же токеном возвращает тот же результат.
- Создание заявки защищено блокировкой.
- Клиентский интерфейс не показывает ложную ошибку только потому, что Apps Script отвечает медленно.
- Медленные вторичные операции отделены от критичного сохранения статуса.
