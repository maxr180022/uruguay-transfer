URUGUAY TRANSFER — VERSION 26

Основа: рабочая V25.

Изменено ТОЛЬКО для междугородних поездок:

1. Междугородняя поездка — в одну сторону:
   предварительная ставка — от 65 UYU/км.

2. Междугородняя поездка — туда и обратно:
   предварительная ставка — от 45 UYU/км.

3. Для обеих услуг:
   - это предварительная стоимость километра;
   - итоговую стоимость рассчитывает водитель после уточнения маршрута;
   - платные дороги и другие дополнительные расходы в ставку не входят;
   - приложение не рассчитывает окончательную сумму автоматически.

4. В сообщениях/итоге для междугорода фраза
   «Рассчитывается администратором» заменена на
   «Рассчитывается водителем».

Вся остальная логика V25 не изменена:
- личный водитель 600 UYU/час;
- минимальный заказ 3 часа;
- Telegram;
- Google Calendar;
- предоплата 2 часа;
- скидки;
- корпоративный режим;
- багаж;
- детский бустер;
- способы оплаты.
